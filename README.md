# AI Interview

An intelligent mock interview and career preparation platform designed to help job seekers practice realistic technical and behavioral interviews with real-time feedback.

## Features

- **Realistic AI Mock Interviews**: Interactive AI-driven interview simulations.
- **Real-Time Analysis**: Instant evaluation of answers, communication clarity, and confidence.
- **Detailed Feedback & Scoring**: Actionable improvement tips and performance metrics.
- **Progress Tracking**: Comprehensive history and analytics dashboard.

## Tech Stack

- **Frontend**: React, TypeScript, Vite, Tailwind CSS, Lucide Icons, Shadcn UI
- **Routing & State**: React Router, TanStack Query
- **Styling**: Tailwind CSS & Tailwind Animate

## Getting Started

### Prerequisites
- Node.js (v18+) & npm

### Installation & Local Setup

```bash
# 1. Clone repository
git clone https://github.com/salmankhan2005/AI-iNTERVIEW.git

# 2. Navigate to project directory
cd AI-iNTERVIEW

# 3. Install dependencies
npm install

# 4. Start development server
npm run dev
```
